# Contributing

Use Python 3.11 and Node.js 24, install the locked dependencies and run the maintained checks in [development](docs/development.md).

Keep adapter changes covered by recorded non-secret fixtures or deterministic fakes. Do not use production accounts or user data in tests. Preserve multilingual content and callback identifiers when editing bot code.

Keep pull requests focused, describe the resulting behavior and list the checks actually performed. Configure secret scanning locally and review staged files before pushing.
