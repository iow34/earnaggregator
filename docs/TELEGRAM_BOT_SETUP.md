## 🤖 Реєстрація бота в Telegram

### Крок 1: Створення бота через BotFather

1. **Відкрийте Telegram** на MacBook або iPhone
2. **Знайдіть @BotFather** - це офіційний бот для створення ботів
3. **Надішліть команду** `/newbot`
4. **Введіть ім'я бота** (наприклад: `EarnAggregator Bot`)
5. **Введіть username бота** (наприклад: `earn_aggregator_bot`)

⚠️ **Важливо:**

- Username має закінчуватися на `bot` або `_bot`
- Username має бути унікальним
- Збережіть отриманий **токен** - це секретний ключ доступу

### Крок 2: Налаштування бота (опціонально)

Після створення надішліть @BotFather:

- `/setdescription` - додати опис бота
- `/setabouttext` - додати короткий опис
- `/setuserpic` - встановити аватар (логотип EarnAggregator)

### Приклад токена

```
REMOVED_TELEGRAM_EXAMPLE_TOKEN_1
```

## 🔧 Налаштування проекту

### Крок 1: Розміщення токена в проекті

**Файл: `.env`** (в корені проекту)

```env
# =============================================================================
# Telegram Bot Configuration
# =============================================================================
BOT_TOKEN=REMOVED_TELEGRAM_EXAMPLE_TOKEN_1

# =============================================================================
# Application Settings
# =============================================================================
ENVIRONMENT=development
LOG_LEVEL=INFO
API_RELOAD=true

# =============================================================================
# Database
# =============================================================================
DATABASE_URL=postgresql+asyncpg://yield_user:yield_secure_password_2024@postgres:5432/yield_db

# =============================================================================
# Redis
# =============================================================================
REDIS_URL=redis://redis:6379/1

# =============================================================================
# Data Service
# =============================================================================
DATA_SERVICE_URL=http://yield-api:8000
REQUEST_TIMEOUT=10.0
```

### Крок 2: Перевірка секретних даних

❌ **НЕ розміщуйте в коді:**

- Токен бота напряму в Python файлах
- Паролі до БД в коді
- API ключі бірж

✅ **Правильно розміщуйте:**

- Всі секрети тільки в `.env` файлі
- `.env` має бути в `.gitignore`
- Використовуйте змінні середовища через `settings`

## 🚀 Запуск бота

### Варіант 1: Локальний запуск (розробка)

```bash
# 1. Перейти до проекту
cd /Users/user777/Documents/EarnAggregator

# 2. Запустити всі сервіси
docker-compose up -d

# 3. Перевірити що все працює
docker-compose ps

# 4. Перевірити логи бота
docker-compose logs -f telegram-bot
```

### Варіант 2: Тільки бот (якщо інші сервіси вже запущені)

```bash
# В окремому терміналі
cd /Users/user777/Documents/EarnAggregator

# Запустити тільки бота
docker-compose up telegram-bot
```

### Варіант 3: Ручний запуск без Docker (для розробки)

```bash
# 1. Активувати віртуальне середовище
source venv/bin/activate

# 2. Перейти до бота
cd yield-telegram-bot

# 3. Встановити залежності
pip install -r requirements.txt

# 4. Запустити бота
python -m bot.main
```

```bash

# Перевірка

docker-compose -f docker-compose.prod.yml logs telegram-bot
```

## 🆘 Troubleshooting

### Проблема: Бот не відповідає

**Перевірте:**

1. Чи запущений контейнер: `docker-compose ps`
2. Чи правильний токен: `echo $BOT_TOKEN`
3. Логи: `docker-compose logs telegram-bot`
4. Чи доступний API: `curl http://localhost:8000/health`

### Проблема: Помилка "Database not initialized"

**Рішення:**

```bash
# Перезапустити всі сервіси
docker-compose down -v
docker-compose up -d --build
```

### Проблема: Бот відповідає, але дані не приходять

**Перевірте:**

1. Чи працює yield-data-service: `curl http://localhost:8000/api/v1/health`
2. Чи правильний DATA_SERVICE_URL в .env
3. Логи API: `docker-compose logs yield-api`
