# ✅ **Частина 1. Архітектура системи локалізації + створення структури файлів RU**

Ця частина включає:

1. **Загальний підхід до локалізації в боті**
2. **Які саме файли потрібно створити під російську мову**
3. **Що саме має бути перекладено на RU**
4. **Структура RU-файлів**
5. **Технічні вимоги до реалізації**

---

# #️⃣ **1. Загальний підхід до локалізації (архітектура)**

Система локалізації має спиратися на:

### **1.1. Централізований менеджер локалізації**

Створюється файл:

```
bot/localization/manager.py
```

Він:

* завантажує всі JSON файли локалізації (українські, російські, англійські)
* надає функції:

  * `get_text(key, lang)`
  * `get_menu_text(key, lang)`
  * `get_error_text(key, lang)`
  * `get_table_text(key, lang)`
* містить **fallback логіку**: якщо RU-текст не знайдено → `ua` → ключ.

---

### **1.2. Структура каталогу**

На основі документа:

```
bot/localization/texts/
    ui.json              ← інтерфейс кнопок
    messages.json        ← системні повідомлення
    errors.json          ← тексти помилок
    navigation.json      ← кнопки навігації
    tables.json          ← заголовки таблиць
    search.json          ← фільтри і пошук
    sections.json        ← заголовки секцій
    language.json        ← вибір мови
```

У кожному файлі буде блок:

```json
{
  "ua": { ... },
  "ru": { ... },
  "en": { ... }
}
```

Ти перекладатимеш **тільки RU-секцію**.

---

### **1.3. Де буде зберігатися мова користувача**

У БД:

* в таблицю `telegram_users` додається:

```
language VARCHAR(2) DEFAULT 'ua'
```

# #️⃣ **5. Технічні вимоги для реалізації RU-локалізації**

### **5.1 Всі поля меню/повідомлень у коді повинні використовувати тільки ключі**

❌ не можна:

```python
message.answer("Вітаємо…")
```

✔️ потрібно:

```python
message.answer(localization.get_text("menu.main.welcome", lang))
```

---

### **5.2 Усі функції в handlers повинні приймати параметр lang**

Наприклад:

```python
async def show_main_menu(message, lang):
```

---

### **5.3 Усі клавіатури генеруються через локалізацію**

У файлі `keyboards/reply.py`:

```
text = localization.get_menu_text("menu.main.exchanges", lang)
```

---

### **5.4 Динамічні таблиці отримують RU-тексти із tables.json**

У `formatters.py`:

```python
header_product = localization.get_text("table.header.product", lang)
```

---

### **5.5 Рекурсивний fallback для RU**

* якщо ключ відсутній у RU → UA → EN → ключ

# #️⃣ **1. Підготовка системи локалізації**

## **1.1 Створити каталог локалізації**

Створити структуру:

```
bot/localization/
    ├── __init__.py
    ├── manager.py
    └── texts/
         ├── ui.json
         ├── messages.json
         ├── errors.json
         ├── navigation.json
         ├── tables.json
         ├── search.json
         ├── sections.json
         └── language.json
```

## **1.2 Створити клас LocalizationManager**

Файл:

```
bot/localization/manager.py
```

Клас повинен:

* завантажувати всі JSON файли при старті
* кешувати їх у памʼяті
* мати fallback (ru → ua → en → key)
* мати API:

```
get_text(key, lang)
get_menu_text(key, lang)
get_error_text(key, lang)
get_table_text(key, lang)
```

## **1.3 Створити глобальний екземпляр**

Файл:

```

```

```python
from .manager import LocalizationManager

localization = LocalizationManager()
__all__ = ["localization"]
```

# #️⃣ **4. Інтеграція параметра lang у всі хендлери**

У кожному `handlers/*.py`:

1. Додати отримання мови:

```python
lang = user.language
```

2. Додавати параметр lang у всі функції генерації контенту:

❌ так:

```python
await message.answer("Вітаємо!")
```

✔️ треба:

```python
await message.answer(localization.get_text("menu.main.welcome", lang))
```

## **4.1 Модифікації в конкретних файлах (обовʼязкові)**

* всі системні тексти замінити на localization.get_text()

# #️⃣ **8. Алгоритм вибору та збереження мови**

### Опис процесу:

1. Користувач натискає кнопку "🌐 Language"
2. Бот показує меню вибору:

```
🇺🇦 Українська
🇷🇺 Русский
🇬🇧 English
```

3. Зберігається в БД:

```
user.language = "ru"
```

4. Бот відповідає:

```
success.language_selected
```

5. Усі подальші хендлери використовують тільки lang у викликах локалізації.

# ✅ **ЧАСТИНА 4. Гайд по правильному перекладу текстів бота на російську мову**


# #️⃣ 4.1. **Стиль і тон російської мови**

### ✔️ Використовувати:

* нейтральний, професійний стиль
* лаконічні формулювання
* короткі інструктивні речення
* ввічливе звертання на "вы"

### ❌ Не використовувати:

* сленг (крім загально криптовалютного)
* розмовні конструкції
* "тыканье"
* жаргон, не пов’язаний з криптою

---

# #️⃣ 4.2. **Основні принципи перекладу інтерфейсу**

### ✔️ Короткі кнопки, без непотрібних слів

Українське: **"Назад до списку"**
Російське: **"⬅️ Назад"** або **"⬅️ К списку"**

### ✔️ Зберігати емодзі без змін

Емодзі — частина UI-системи.

### ✔️ Довгі пояснення розбивати на 2–3 короткі речення

### ✔️ Уникати кальки

Наприклад:

❌ "Переключить на Украинский язык"
✔️ "Изменить язык на украинский"

---

# #️⃣ 4.3. **Правильна крипто-термінологія російською**

Це критично, адже неправильний переклад дискредитує бота.

# #️⃣ 4.4. **Переходи, навігація, кнопки: правила перекладу**

### Основні правила:

1. Кнопки завжди дуже короткі
2. Без розширених форм
3. Без фраз типу “Пожалуйста, выберите…”
4. Важливо: **кнопка повинна займати мало місця в UI Telegram**

### Правильні переклади:

UA → RU

* ⬅️ Назад — ⬅️ Назад
* ⬅️ На головну — ⬅️ В меню
* Наступна ➡️ — Далее ➡️
* Показати всі продукти — Все продукты
* 🔍 Пошук — Поиск
* ♻️ Скинути — Сброс
* 🔍 Фільтр — Фильтр
* 🏦 Біржі — Биржи

---

# #️⃣ 4.5. **Переклад таблиць**

### Заголовки таблиць:

UA → RU

* № — №
* Продукт — Продукт
* Біржа — Биржа
* APY — APY
* Тип — Тип
* Період — Период
* Flexible — Flexible
* Locked — Locked

### Правила:

* Не перекладати біржові терміни (Flexible/Locked).
* Підтримувати однакову структуру таблиць для всіх мов.
* Числа, проценти, дати — форматувати так само, як в UA.

---

# #️⃣ 4.6. **Переклад повідомлень про помилки**

Помилки повинні бути:

* короткі
* точні
* без води
* без емоційності

Правильні шаблони:

UA → RU

* ❌ Сталася помилка — ❌ Произошла ошибка
* ⚠️ Система тимчасово недоступна — ⚠️ Система временно недоступна
* 📭 Нічого не знайдено — 📭 Ничего не найдено
* 💡 Спробуйте змінити критерії — 💡 Попробуйте изменить критерии

* експертна,
* ділова,
* з чіткими інструкціями,
* без емоційних перебільшень.

### ✔️ Вживати:

* "Вы можете...";
* "Рекомендуется...";

### ❌ Уникати:
