
**Технічне завдання: Сортування продуктів у Telegram-боті за параметром “Популярні”**

🎯 Мета:
Реалізувати функціонал сортування списку продуктів у Telegram-боті (в таблиці візуалізації APY даних) за параметром популярності токена, базуючись на рейтингу топових монет з CoinGecko API.


1. Джерело даних

API: CoinGecko Public API v3
https://docs.coingecko.com/

Плануються використовувати безплатний варіант API.

Ендпоінт для топ монет:
GET https://api.coingecko.com/api/v3/coins/markets?vs_currency=usd&order=market_cap_desc&per_page=250&page=1

📌 Повертає список монет із ключовими параметрами:

- id — внутрішній ідентифікатор CoinGecko (наприклад, "bitcoin")
- symbol — тикер монети (наприклад, "btc")
- name — назва (наприклад, "Bitcoin")
- market_cap_rank — позиція у рейтингу за ринковою капіталізацією
- current_price — поточна ціна (необов’язково для сортування)


2. Структура зберігання даних у базі
Таблиця coins_popularity

Зберігає дані рейтингу з CoinGecko.

| Поле            | Тип                  | Опис                                                 |
| --------------- | -------------------- | ---------------------------------------------------- |
| id              | SERIAL / PRIMARY KEY | Унікальний ідентифікатор запису                      |
| coin_id         | VARCHAR              | ID монети з CoinGecko (`bitcoin`, `ethereum` і т.д.) |
| symbol          | VARCHAR              | Тикер монети (`BTC`, `ETH`...)                       |
| name            | VARCHAR              | Повна назва монети                                   |
| market_cap_rank | INTEGER              | Рейтинг популярності (1 = найпопулярніша)            |
| updated_at      | TIMESTAMP            | Час останнього оновлення даних                       |

Таблиця exchange_products

Зберігає продукти бірж із бази APY.

| Поле          | Тип                  | Опис                                 |
| ------------- | -------------------- | ------------------------------------ |
| id            | SERIAL / PRIMARY KEY | Ідентифікатор продукту               |
| exchange_name | VARCHAR              | Назва біржі (Bybit, Binance, OKX...) |
| token_symbol  | VARCHAR              | Символ токена (`BTC`, `ETH`...)      |
| apy           | FLOAT                | Поточна річна прибутковість          |
| other_fields  | ...                  | Інші характеристики продукту         |


3. Алгоритм оновлення даних популярності
3.1. Завантаження рейтингу з CoinGecko

- Раз на день (або за запитом адміністратора) бот викликає CoinGecko API.
- Отримані 250 топових монет зберігаються у таблиці coins_popularity.
- Якщо монета вже існує — оновлюється market_cap_rank та updated_at.

3.2. Мапінг токенів між CoinGecko і біржовими продуктами

- Порівнювати symbol з поля exchange_products.token_symbol та coins_popularity.symbol.
- Використати уніфікацію символів:
- перевести всі символи у верхній регістр (upper());
- видалити пробіли або суфікси біржових токенів (наприклад, BTCUSDT → BTC);
- у випадку відсутності прямого збігу — залишати NULL у полі рейтингу.


4. Механізм сортування
4.1. Коли користувач обирає “Сортувати за популярністю”

- Отримати список продуктів з бази exchange_products.
- Зробити LEFT JOIN з таблицею coins_popularity по token_symbol = symbol.
- Відсортувати за market_cap_rank ASC (тобто від 1 до N).
- Якщо токен не знайдено у CoinGecko — ставити йому рейтинг 9999 (в кінець списку).


5. Відображення у Telegram боті

При виборі кнопки “Сортувати за популярністю” (наприклад, у inline-кнопках фільтра):

- Застосовується запит з сортуванням.
- Формується оновлена таблиця продуктів (наприклад, у вигляді топ-списку).
- Відображається у повідомленні з можливістю перемикання сторінок (pagination).


6. Додаткові вимоги

- Якщо CoinGecko API недоступне — використовувати кешовану версію з останнього оновлення.
- Передбачити логування помилок API-запиту та часу оновлення.
- Додати флаг is_popularity_synced у таблиці exchange_products, щоб відстежувати, які токени вдалося зіставити.
- Можливість ручного перезапуску оновлення через адмін-команду /update_popularity.


Результат реалізації

- Після впровадження користувач у Telegram-боті зможе:
- Натиснути кнопку «Сортувати: Популярні»;
- Отримати оновлений список продуктів у порядку рейтингу CoinGecko TOP;
- Бачити релевантну таблицю з найпопулярнішими монетами вище у списку.

Таблиця для зберігання даних із CoinGecko TOP.
