🆘 <b>ChainAdvisor Bot - Полное руководство</b>

Бот помогает найти лучшие предложения пассивного дохода на криптовалютных биржах.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📱 <b>Функции главного меню:</b>

🏠 <b>Главное меню (Страница 1)</b>
   • Просмотр ТОП-10 трендовых криптовалют
   • Быстрый доступ к популярным монетам: BTC, ETH, SOL, USDT
   • Просмотр продуктов по биржам (Binance, Bybit, OKX и т.д.)
   • Нажмите на одну из кнопок для подробной информации о доходности: Все продукты, Flexible, Locked, Расширенный поиск

🎯 <b>Recommendations (Рекомендации)</b>
   • 10 практических советов по работе с Earn продуктами
   • Доступные темы:
     📝 Перевод между биржами с минимальными комиссиями
     📝 Flexible vs Locked - когда выбирать
     📝 Критерии выбора earn-продуктов
     📝 Диверсификация инвестиций
     📝 Мониторинг APY и рисков
     📝 Реферальные программы
     📝 Компаундинг дохода
     📝 Снижение рисков во время волатильности
     📝 Проверка надежности биржи
     📝 Планирование портфеля на основе целей
   • Каждая рекомендация содержит пошаговую инструкцию с примерами

🏦 <b>Продукты биржи (Страница 2)</b>
   • Просмотр всех продуктов конкретной биржи
   • 📊 Сортировка продуктов по APY, популярности
   • Табличный вид: Продукт, Тип, APY, Длительность
   • Пагинация для удобного просмотра

📋 <b>Отфильтрованные просмотры (Страницы 3-9)</b>
   • <b>Страница 3</b>: Все Flexible продукты со всех бирж
   • <b>Страница 4</b>: Все Locked продукты со всех бирж
   • <b>Страница 5</b>: Конкретный продукт на всех биржах
   • <b>Страницы 6-9</b>: Различные комбинации фильтров, кнопка Расширенный поиск

🔍 <b>Как использовать фильтры:</b>
   1. Нажмите кнопку 🔍 <b>Фильтр</b> на любой странице
   2. Выберите ваши критерии (продукт, биржа, тип)
   3. Примените фильтры для просмотра соответствующих результатов
   4. Используйте 🔄 <b>Сбросить фильтры</b> для сброса
   5. Навигация кнопками ◀️ ▶️ для пагинации

💡 <b>Полезные советы:</b>
   • Используйте кнопки меню внизу для быстрого доступа
   • Нажимайте на перейти для перехода на биржу
   • Flexible продукты = вывод в любое время
   • Locked продукты = более высокий APY, но фиксированный период удержания
   • Сравнивайте APY на разных биржах перед инвестированием

📊 <b>Понимание APY:</b>
   • APY (Annual Percentage Yield) - годовая ставка доходности
   • Более высокий APY = более высокая потенциальная прибыль
   • Учитывайте уровень риска: Stablecoins (более низкий APY, безопаснее) vs Altcoins (более высокий APY, рискованнее)

⚡ <b>Быстрые команды:</b>

   • /help - Показать это руководство
   • /recommendations - Просмотреть все рекомендации
   • /exchanges - Показать список всех бирж
