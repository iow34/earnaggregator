🆘 <b>ChainAdvisor Bot - Повний посібник</b>

Бот допомагає знайти найкращі пропозиції пасивного доходу на криптовалютних біржах.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📱 <b>Функції головного меню:</b>

🏠 <b>Головне меню (Сторінка 1)</b>
   • Перегляд ТОП-10 трендових криптовалют
   • Швидкий доступ до популярних монет: BTC, ETH, SOL, USDT
   • Перегляд продуктів за біржами (Binance, Bybit, OKX тощо)
   • Клацніть на одну із кнопок для детальної інформації про доходність: Всі продукти, Flexible, Locked, Розширений пошук

🎯 <b>Recommendations (Рекомендації)</b>
   • 10 практичних порад по роботі з Earn продуктами
   • Доступні теми:
     📝 Переказ між біржами з мінімальними комісіями
     📝 Flexible vs Locked - коли обирати
     📝 Критерії вибору earn-продуктів
     📝 Диверсифікація інвестицій
     📝 Моніторинг APY та ризиків
     📝 Реферальні програми
     📝 Компаундинг доходу
     📝 Зниження ризиків під час волатильності
     📝 Перевірка надійності біржі
     📝 Планування портфеля на основі цілей
   • Кожна рекомендація містить покрокову інструкцію з прикладами

🏦 <b>Продукти біржі (Сторінка 2)</b>
   • Перегляд усіх продуктів конкретної біржі
   • 📊 Сортування продуктів по APY, популярності
   • Табличний вигляд: Продукт, Тип, APY, Тривалість
   • Пагінація для зручного перегляду

📋 <b>Відфільтровані перегляди (Сторінки 3-9)</b>
   • <b>Сторінка 3</b>: Усі Flexible продукти з усіх бірж
   • <b>Сторінка 4</b>: Усі Locked продукти з усіх бірж
   • <b>Сторінка 5</b>: Конкретний продукт на всіх біржах
   • <b>Сторінки 6-9</b>: Різні комбінації фільтрів, кнопка Розширений пошук

🔍 <b>Як використовувати фільтри:</b>
   1. Натисніть кнопку 🔍 <b>Фільтр</b> на будь-якій сторінці
   2. Оберіть ваші критерії (продукт, біржа, тип)
   3. Застосуйте фільтри для перегляду відповідних результатів
   4. Використовуйте 🔄 <b>Скинути фільтри</b> для скидання
   5. Навігація кнопками ◀️ ▶️ для пагінації

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎯 <b>Підтримувані криптовалюти:</b>
BTC, ETH, SOL, USDT, USDC, BNB, ADA, DOT, XRP, AVAX, MATIC, LINK, UNI та багато інших

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🏦 <b>Підтримувані біржі:</b>
Binance, Bybit, OKX, MEXC, Gate.io, BitMart, Bitget, Kraken, KuCoin, HTX, Nexo

💡 <b>Корисні поради:</b>
   • Використовуйте кнопки меню внизу для швидкого доступу
   • Натискайте на перейти для переходу на біржу
   • Flexible продукти = виведення в будь-який час
   • Locked продукти = вищий APY, але фіксована період утримання
   • Порівнюйте APY на різних біржах перед інвестуванням

📊 <b>Розуміння APY:</b>
   • APY (Annual Percentage Yield) - річна ставка прибутковості
   • Вищий APY = вищий потенційний прибуток
   • Враховуйте рівень ризику: Stablecoins (нижчий APY, безпечніше) vs Altcoins (вищий APY, ризикованіше)

🌐 <b>Language (Мова)</b>
   • Функція вибору мови (скоро)
   • Наразі підтримується українська та англійська

⚡ <b>Швидкі команди:</b>
   • /main - Показати головне меню з трендовими монетами
   • /help - Показати цей посібник
   • /recommendations - Переглянути всі рекомендації
   • /exchanges - Показати список всіх бірж
